# Nestor

De check-in app van [Nestor](https://github.com/BenxFPG1), een deadman switch.
Voeg de pagina toe aan je beginscherm; dan gedraagt hij zich als een app.

Deze repo bevat alleen de voorkant: één HTML-bestand, een manifest en twee
iconen. Er staan geen secrets in. Het device secret wordt op je telefoon
ingevoerd en blijft in de localStorage van je browser; de backend accepteert
niets zonder dat secret.
